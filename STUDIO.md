# Open TAN — laws, router and workflow (Image is the hub · Video · 3D)

> **LAW 1 — ASK FIRST, THEN MAKE (owner 2026-11-14: "whenever you start, ask me some few questions before image generation … what is the aspect ratio … if I tell a specific aspect ratio, you go for that").** Before ANY image: ONE question message (the ask list in law 2). Nothing is generated before the owner answers. A ratio the owner names is final — never "improved". `studio verify` A01 blocks a brief without `asked`. The same one ask message comes first for every video and 3D job (step 2 of their workflows).
> **LAW 3 — THE OWNER'S WORDS CHOOSE THE ART DIRECTION (owner 2026-11-14: "whenever I use wordings, according to the wordings you should generate posters").** `studio direct "<exact words>"` → family + recipe from the 75 references. Never a freehand poster. Full text: Owner laws → 3.
> **LAW 6 — CLIENT LOGO GOES IN, IN A CORNER (owner 2026-11-14: "the logo placement should not be always on the top … somewhere in the right or left corner … input image generation with a prompt that uses the logo and the exact text on the logo, the font").** The real logo file is ATTACHED to the ChatGPT generation and the prompt names its exact text + font + corner (top-right default, top-left when the layout leans right). Never top centre. Kannada letters off → rerun with `--logo-overlay` (clear corner, real file pasted after). `studio verify` L01/L03 block a client poster without it.
> **LAW 19 — PROMPT BY THE BOOK (owner 2026-11-14: "the milk packet was also painted … the problem is in your prompting step technique … this is the official documentation of ChatGPT … add it as a law, add it as a pre-prompting technique").** Every image prompt follows `guide/PROMPTING.md` (OpenAI's image-prompting guide): labelled sections, numbered image roles (Image 1 = reference LAYOUT ONLY), photographic elements called a real photograph and never painted, the reference geometry written out (`refLayout`), exact text, constraints. The pre-prompt check runs before every generation and blocks a bad prompt.
