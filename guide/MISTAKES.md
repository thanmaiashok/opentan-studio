# MISTAKES — every mistake the owner caught, why it happened, and what now PREVENTS it
Rule (same as FoxMotion): a mistake is fixed only when (a) the cause is fixed in the tools or the habit and (b) a check catches it automatically (`studio verify`). Notes alone don't count. Add a row here + a check whenever the owner reports something new.
